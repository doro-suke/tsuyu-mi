# Memorize Lesson Skill

## 概要
AIが自身の経験から学習し、セッションを超えて知見を継承するためのスキル。

## 実行トリガー
- 解決に複数ターンを要した複雑なエラーを解消したとき。
- ユーザーから「今後はこうしてほしい」という設計上の強い要望を受けたとき。
- 既存のルールでは対応できない新しい実装パターンを発見したとき。

## 手順
1. **Analyze**: 現在のセッション履歴を振り返り、「何が問題だったか」「どう解決したか」「次からどうすべきか」を抽出する。
2. **Read**: `docs/lessons.md` を読み込み、既に類似の知見が記録されていないか確認する。
3. **Format**: 規定のテンプレートに従い、新しい知見をMarkdown形式で構成する。
4. **Append**: `docs/lessons.md` の末尾（または適切なセクション）に追記する。
5. **Confirm**: 追記した内容を簡潔にユーザーに報告し、学習が完了したことを伝える。

## 成功の定義
- `docs/lessons.md` に具体的で再利用可能な知見が追記されていること。
- 追記された内容が、将来の同様のタスクにおいてAIの行動を抑制または促進できる明確な「ルール」を含んでいること。
