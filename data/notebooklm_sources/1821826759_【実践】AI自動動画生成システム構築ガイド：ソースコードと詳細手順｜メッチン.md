## 本文
はじめに前回の記事「PythonとAIで動画生成！モザイクノイズと格闘した開発記録」では、AIを活用したニュース風刺ショート動画生成システムの開発過程で直面した画質劣化問題とその解決策について解説しました。本記事では、そのシステムを実際に構築し、運用するための具体的な手順、使用したプロンプトの詳細、そしてプログラムの全ソースコードを公開します。AIによるコンテンツ生成に興味がある方、Pythonでの自動化に挑戦したい方、そして前回の記事でシステムの全体像に触れた方のために、実践的なガイドとしてまとめました。システム概要の再確認本システムは、以下の主要なステップで構成されています。ニュース取得: Google News RSSフィードから最新のヘッドラインを自動で取得します。風刺テーマ・プロンプト生成: 取得したニュースヘッドラインに基づき、Google Gemini APIを活用して風刺的なテーマと、そのテーマに沿ったStable Diffusion用の画像生成プロンプトを自動生成します。画像生成: 生成されたプロンプトを元に、ローカルで動作するStable Diffusion Web UI (Automatic1111) のAPIを通じて画像を生成します。動画編集: PythonのMoviePyライブラリを使用し、生成された画像、自動選定されたBGM、そして風刺テーマを組み合わせてショート動画を作成します。この際、画質劣化を防ぐための様々な工夫が凝らされています。YouTubeアップロード: 完成した動画をYouTube Data API v3 を利用してYouTubeチャンネルに自動でアップロードします。構築のための事前準備システムを構築する前に、いくつかのツールと環境を準備する必要があります。1. Python環境Python: 3.8以上のバージョンを推奨します。仮想環境 (venv): プロジェクトごとに依存関係を管理するため、仮想環境の利用を強く推奨します。python -m venv venv .\venv\Scripts\activate # Windowsの場合 # source venv/bin/activate # macOS/Linuxの場合 2. 必要なPythonライブラリのインストール仮想環境をアクティベートした後、以下のライブラリをインストールします。pip install moviepy==1.0.3 # 動画編集
pip install google-generativeai # Gemini API連携
pip install requests # Web API通信
pip install Pillow # 画像処理
pip install python-dotenv # 環境変数管理
pip install feedparser # RSSフィード解析
pip install google-auth-oauthlib # YouTube API認証
pip install google-api-python-client # YouTube APIクライアント
pip install wand # ImageMagick連携 (MoviePyが内部的に使用)


3. Stable Diffusion Web UI (Automatic1111)インストール: Stable Diffusion Web UI (Automatic1111) がローカルにインストールされ、動作することを確認してください。APIの有効化: Web UIを起動する際に、APIリクエストを受け付けられるように設定する必要があります。webui-user.bat (または対応する起動スクリプト) をテキストエディタで開き、set COMMANDLINE_ARGS= の行に --api を追加して保存します。4. FFmpegとImageMagickMoviePyが動画や画像を処理するために利用する外部ツールです。FFmpeg: 公式サイトからWindows版のバイナリをダウンロードし、解凍したフォルダ内のbinディレクトリにあるffmpeg.exe, ffprobe.exe, ffplay.exeを、Python仮想環境のScriptsフォルダ (F:\vid_gen\venv\Scriptsなど) にコピーします。ImageMagick: 公式サイトからWindows版のDLL版（例: ImageMagick-6.9.13-25-Q8-x64-dll.exe）をダウンロードし、インストールします。インストール時に「Add application directory to your system path」にチェックが入っていることを確認してください。5. APIキーと認証情報Google Gemini APIキー: Google AI StudioでGemini APIキーを取得し、.envファイルにGEMINI_API_KEY="YOUR_API_KEY"として保存します。YouTube APIクライアントシークレット: Google Cloud ConsoleでYouTube Data API v3を有効にし、OAuth 2.0クライアントIDを作成します。ダウンロードしたJSONファイルをclient_secrets.jsonという名前でプロジェクトのルートディレクトリに保存します。.envファイルにはYOUTUBE_CLIENT_SECRETS="client_secrets.json"と記述します。プログラムのソースコード以下に、ニュース風刺ショート動画を自動生成するPythonスクリプト video_gen.py の全ソースコードを公開します。
