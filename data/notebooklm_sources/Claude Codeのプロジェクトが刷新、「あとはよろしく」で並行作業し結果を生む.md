# Claude Codeのプロジェクトが刷新、「あとはよろしく」で並行作業し結果を生む

## 本文
人間がタスクを分割してClaudeに手渡し、その結果をまたつなぎ合わせる手間から解放される。Anthropicは9月17日(米国時間)、Claude Codeの「プロジェクト」機能を刷新してベータ版として提供を開始した。Claude Codeでクラウドセッションを利用しており、かつWeb版/デスクトップ版で既存のプロジェクトを持たない一部のPro/Maxプランの契約者から展開する。  　新しいプロジェクトでは、ユーザーが「何をやるべきか」を伝えると、Claudeが依頼内容に応じて範囲を定め、並行して動く複数の「スレッド」に作業を委任して調整し、各スレッドの成果物を確認したうえで最終成果物をまとめる。  　ユーザーがプロジェクトを設定し、クラウド環境、コネクタやプラグイン、指示、モデルなどを構成して複数の作業を依頼するだけで、あとは自動的に作業が進行し、結果が報告される。  　スマートフォンからも進捗の確認や指示ができ、PCから離れた後もプロジェクトは作業を続ける。また、すべてのスレッドが情報を共有メモリに読み書きするため、複雑なプロンプトエンジニアリングの必要性を減らせるとしている。  　なお、複数のスレッドがそれぞれClaude Codeのフルセッションとして動作するため、使用量の上限に早く到達する可能性がある。プロジェクト単位の使用量を確認できるほか、コーディネータチャットとワーカースレッドそれぞれで使用するモデルや推論努力レベルを選択できる。  　現在、スレッドはクラウド上で実行されているが、近くローカルツールやコードと並行して自分のPC上で実行できるようになるという。
