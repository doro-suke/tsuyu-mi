### 概要
東大大学院で機械学習×材料の研究をしている修士2年の著者が、Claude Codeを使い始めて約半年間で、日常業務を45個のcronジョブで自動化したシステムの全容を公開した記事です。

### 全体像：何がどう動いているか
macOS上で24時間稼働しており、Claude CLIを「考えるパーツ」として利用しています。
- **cronジョブ**: 45本（5分〜週次で実行）
- **カスタムエージェント定義**: 36個
- **Pythonスクリプト**: 132本（データ取得・加工用）
- **Slackチャンネル**: 12個（通知・レポート用）

### カテゴリ別の自動化内容
1. **メール処理（最も効果大）**
   - Gmail APIで10分ごとに取得し、AIが4段階（reply, action, see, skip）に分類。
   - 返信下書きの自動生成やタスク登録を行い、1日20〜30分を節約。
2. **日程調整**
   - ICS URLからカレンダー情報を取得し、メール返信時に空き日程を自動挿入。
3. **論文の新着監視**
   - RSSやPubMed APIから取得した論文をAIが5段階評価し、日本語要約をSlackに投稿。
4. **日次・週次レポート**
   - gitコミット、タスク、cron実行状況をClaudeが要約して毎日・毎週生成。
5. **AI・テクノロジー情報収集**
   - ニュースを自動収集・要約し、SNS巡回の時間を削減。
6. **面談・ミーティングの記録**
   - 録音ファイルをフォルダに置くだけで、数分後にSlackへ要約が届く。
7. **MLコード開発での活用**
   - 雛形生成、デバッグ、リファクタリング、テスト生成などのペアプロ。
8. **システムの自己監視**
   - 毎日9時にヘルスチェックを行い、エラーがあればSlackに通知。

### 自動化の設計原則
- **原則1：「判断」と「作業」を分離する**
  - AIには下書きや通知までをさせ、最終判断（送信など）は人間が行う。
- **原則2：壊れにくい方法を選ぶ**
  - APIよりICS URL、スクレイピングよりRSSなど、安定性を重視。
- **原則3：Slackを「ダッシュボード」にする**
  - 全ての情報をSlackに集約し、一箇所で状況把握できるようにする。
- **原則4：5分で作れるものから始める**
  - 小さく始めて、必要に応じて機能を育てる。

### コスト
- **合計：約15,000円/月**
  - 主な内訳はClaude Code (Max plan) の$100。サーバー代やSlack、Gmail APIは無料枠。
