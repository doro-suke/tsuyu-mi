## 本文
「Autodesk Flow Studio」と「Codex」で3Dゲームの作成を試したのでまとめました。1. Autodesk Flow Studio で3Dモデルを準備「Autodesk Flow Studio」で画像から3Dモデルを生成します。今回は以下の3つの3Dモデルを作成しました。・女の子・ブロック床・スター(1) ChatGPT で元画像を生成。・girl.png・block.png・star.png(2) 「Autodesk Flow Studio」で3Dモデル生成。モデルのダウンロードにはサブスク加入が必要です。(3) 気になる場合はテクスチャの塗りの補正。スターのテクスチャは裏がイマイチで、1色でも問題ないので、テクスチャでなく単色マテリアルに変更しました。starはテクスチャでなく１色で描画できるならそれでもOK(4) Mixamo から使用するモーションのfbxをダウンロード。今回は以下の4つを使いました。・アイドル (直立)・走る・ジャンプ・勝利(4) プロジェクトフォルダを作って、modelsフォルダにモデルファイル (usdz) 、mothionsフォルダにモーションファイル(fbx) を配置。・models　・girl.usdz　・block.usdz　・star.usdz・motions　・idle.fbx　・run.fbx　・jump.fbx　・victory.fbx(5) モデルファイルとモーションファイルをthree.js用のファイルに変換して、ビューアを作って表示。モデルファイルとモーションファイルをthree.js用のファイルに変換して、ビューアを作って表示して。Vite + TypeScript + Three.js。girl.usdzはvrm、block.usdzとstar.usdzはglbに変換。motionsのファイルはvrmaに変換してgirlのモーションとして再生。2. ChatGPT でゲーム画面のスクリーンショットを準備(1) ChatGPT でゲーム画面のスクリーンショットを作成。・title.png・game.png3. Codex でゲームを作成(1) Codexにゲーム作成を指示。ゲーム画面(game.png)を参考にジャンプゲームを作ってください。 奥方向にスクロールし、生き残り時間とスターでスコアアップ、落ちたらライフ減り、3回でゲームオーバー。 ESCキーで3Dビューアとゲーム画面を切り替える。 必要な絵素材があったらImage Genで生成モデルビューアは1キーを押した時に遷移し、モデルビューアのクローズを押した時にタイトルに戻る。(2) 時々、作り途中のゲームを試遊しては、あれこれ追加指示。スペースを離したら下降し始めて。スターは幅は固定できらきら光るエフェクトを追加ジャンプ中に左右に移動したい。左右キー押した時は少しキャラ方向を傾けて。スクロールはもっとゆっくり。スペースキー押した時にすぐジャンプしはじめて。左右キーの体の傾きはZ軸でなくY軸です。左右キーは1マス分でなく押してるだけ移動して。スターの光るエフェクトはアルファブレンディング的なかっこいいやつで。キャラクターが落ちた時は、縦の波動を表現するアルファブレンドなエフェクトを追加。走ってる時は、速度や風を表現するモーションブラー的なカッコいい派手なエフェクトをつけたいです。奥から外への一点透視法的なラインで表現して。なるべくキャラクターや地面と重ならないように。READY GO!とGAME OVERとStage Clear!の文字を Image Gen で作って。もっと見やすく見栄え良く下落ちた時のエフェクトを円でなく縦線エフェクトで表現して。READY GO!の時は女の子はIdle状態にして。タイトル画面を追加して。title.pngを使ってスター取得のエフェクトは、放射状のアルファブレンドラインなエフェクトにして。マップはランダムでなく固定マップ。 ゴール地点にスターがあり、スターを触るとステージクリア。 全3ステージ。 落ちて爆発見たら、高速バックスクロールしてスタート位置からリスタートの演出。 2キーでマップエディタを開いて、ブロックの追加や削除ができるようにする。スタート位置は固定。ゴール位置は1個。落ちた時、爆発が消えてから、スタート地点にスクロール。スタート地点にスクロールする時は、それまでのブロック床も見えるようにマップエディタはもっと見栄え良く、・緑の四角 : ゴール・黄色の四角 : 通常床・青の四角 : スタート地点 (移動は不可)ゴールまでの長さをUIで指定。ドラッグ&ドロップでなく。クリックで床追加・削除。ゴールはクリックで横移動。エディタのスタートとゴールの位置関係を上下逆に。ゴールのスターの光はもっと派手にして、1回ホワイトアウトして消える感じ。そのあと女の子がくるっと180度回転してからVictoryポーズやって。最後のコマで1秒静止してから次のステージへ。ラストステージのときはタイトル画面へREADY GO!の前にカメラを遠くからマップ全体を移し、女の子の顔にアップしたあと、ゲームスタート時のカメラ位置にいってからREADY GO!背景の空をカメラワークといっしょに動くようにスカイボックスなどにできませんか？HDR的なものを Image Gen で作るなどして落下して、スタート地点にもどって、キャラクターが表示された時、0.5秒待ってから READY GO!して4. 効果音素材サイト で効果音 ・ BGMを準備(1) 効果音は「効果音ラボ」、BGMは「Springin’ Sound Stock」で探して、プロジェクトのsoundsフォルダに配置。・title.mp3 : タイトル画面のBGM (ループ) ※スタートボタン押すまで・bgm.mp3 : プレイ画面のBGM (ループ) ※スターをとる or ゲームーバーまで・start.mp3 : スタートボタン押した時の効果音・jump.mp3 : ジャンプ時・damage.mp3 : 落下して爆発した時・star.mp3 : スター取得した時・goal.mp3 : Victoryポーズ時・gameover.mp3 : ゲームオーバー時・ready.mp3 : Ready時・go.mp3 : Go時5.
