    LPやウェブサイトをAIで作ると、どうしても「AIっぽい」デザインになってしまいますよね。


    デザイナーでなければ的確に指示を出す言語化が難しく、「もっとおしゃれにして」といった曖昧な指示になってしまいがちです。


    今回は、Claude Designを使ってAIっぽさを抜け出すための実践方法を紹介します。



    Claude Designは、ウェブ上でのみ使えるデザイン特化のClaude専用ツールです。


    チャットでの自然言語指示に加え、以下の3つの特徴的な編集機能があります。

            
                コメント機能：修正したい箇所をクリックして直接指示を入力できる
エディットモード：Figmaのようにサイズやカラーを直感的に調整できる
ドローモード：フリーハンドでピンポイントの範囲を指定して修正できる
            

    
    
    
        ドローモードで直感的に編集可能
    



    Claude Designの詳しい内容は、エピソード本編でチェック！


    動画で見るなら →こちら


    音声で聴くなら →こちら





    AIはイラストばかりで表現しようとしがちです。


    チャンネル紹介動画の画像や出演者の写真など、実際の画像を入れるだけでデザインの印象が大きく変わります。



    ブランドロゴやモチーフ素材を画像として添付し「背景を透過して配置して」と指示するだけで、独自の世界観が出せます。



    「なんかダサいけどどう変えたらいいか」と感じたら、その箇所のスクリーンショットを添付して改善案を提案してもらいましょう。


    
    
    


    具体的な提案から良さそうなものを採用するだけでOKです。




    デザインだけでなくコピーも要注意です。指定なしで任せると、意味不明な大げさなブランドコピーが出てきがちです。


    改善のプロンプト例：


    
            
                キャッチコピーが全般的にブランドコピーになっているので、ユーザーにとって何が提供価値なのかがわかるベネフィット訴求のコピーにしてください
            
            
        




    Claude Designはリミットが厳しいため、「Share → Hand off to Claude Code」ボタンでClaude Codeに移行するのがおすすめです。


    Claude Codeでは、ローカルサーバーを起動してデザインを確認しながら修正を進めることができます。


    また、実際にウェブサイトとして公開する必要な様々な作業もClaude Codeで行うのが適しています。

            
                修正を多く行う場合は最初からClaude Codeに移行してしまう方が効率的だと思います。

            


            
                Claude Design：フロントエンドのビジュアルデザインを直感的に作りたい場合。コメントやドロー機能を使った細かい指示がしやすい
Claude Code：リミットに達した後の修正や、バックエンドの実装が必要な場合。修正回数が多い場合はこちらが向いている
