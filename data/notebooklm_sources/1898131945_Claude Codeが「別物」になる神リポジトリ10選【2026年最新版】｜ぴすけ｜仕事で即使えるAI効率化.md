## 本文
Claude Code、使ってる？「使ってるけど、なんか思った通りに動かないんだよな…」って人、めっちゃ多いと思う。実はこれ、Claude Code本体の問題じゃない。拡張機能を入れてないから。素のClaude Codeは「優秀だけど何も知らない新人」みたいなもの。でもここに適切なプラグインやスキルを入れると、一緒に設計してくれる頼れる相棒に変わる。今Xでもこの手の投稿がめちゃくちゃバズってて、「入れるだけで別物になった」って声が続出してる。今回は、GitHubで実際に評価が高くて、自分も使ってるものを含めた神リポジトリ10選を紹介する。初心者でもインストールできるように解説するから、ぜひ最後まで読んでほしい。まず知っておきたい：Claude Codeの拡張の仕組みリポジトリを紹介する前に、Claude Codeの拡張メカニズムを整理しておく。Claude Codeには大きく分けて6つの拡張ポイントがある。CLAUDE.md: プロジェクトのルールを書いておく設定ファイル。毎回自動で読み込まれるSkills（スキル）: 特定の作業をする時だけ読み込まれる専門知識MCP: 外部ツール（GitHub、DB、APIなど）とClaude Codeを繋ぐ仕組みHooks（フック）: ツール実行の前後に自動でコマンドを走らせるトリガーPlugins（プラグイン）: スキル・フック・コマンドなどをまとめてパッケージ化したものカスタムコマンド: /commit とか /review みたいなスラッシュコマンドを自作できる今回紹介するリポジトリは、これらの仕組みを活用してClaude Codeを強化するもの。それぞれ何を解決するのか、を意識して読むとわかりやすいと思う。1. Superpowers — Claude Codeを「シニア開発者」にするGitHub: https://github.com/obra/superpowersスター数: 10万超え（2026年3月時点）カテゴリ: プラグイン（スキル集）今一番バズってるやつ。GitHubで10万スターを超えた化け物リポジトリ。何がすごいかというと、Claude Codeの仕事の進め方そのものが変わる。素のClaude Codeは「よろしく」って投げるといきなりコードを書き始める。でもSuperpowersを入れると、まず「何作りたいの？」って聞いてきて、一緒に設計してから本気で動き出す。完成したら「これでいい？」って確認までしてくれる。具体的には、こんなワークフローが自動で走る。ブレインストーミング → 計画立案 → TDD（テスト駆動開発） → 実装 → コードレビュープログラミング経験がなくても、「何を作りたいか」さえ言えれば動いてくれる。Anthropicの公式マーケットプレイスにも採用済み。迷ったらまずこれを入れるべき。2. Claude-Mem — セッション間の記憶喪失を解決GitHub: https://github.com/thedotmack/claude-memカテゴリ: プラグイン（記憶管理）Claude Codeの最大の弱点、それは**「昨日の自分を覚えてない」こと**。新しいセッションを開くたびに、前回やったことを全部忘れてる。また同じ説明をするところからやり直し…これ、地味にストレス。Claude-Memは、この記憶喪失問題を完全に解決する。仕組みはこう。セッション中のやり取りを自動でキャプチャAIが重要な部分だけを圧縮してベクトルDBに保存次のセッション開始時に、関連するコンテキストを自動で注入つまり、「前回の続きから」が自然にできるようになる。プロジェクトの暗黙知——「このファイルは触らない方がいい」とか「この設計にはこういう理由がある」みたいな情報が、セッションをまたいで引き継がれる。これはでかい。3. GSD（Get Shit Done） — とにかく仕事を終わらせるGitHub: https://github.com/gsd-build/get-shit-doneカテゴリ: メタプロンプト＆コンテキストエンジニアリング名前がいい。「とにかく仕事を終わらせろ」。GSDが解決するのは**「コンテキスト腐敗」**という問題。Claude Codeに長時間作業させると、コンテキストウィンドウが埋まるにつれて出力品質が落ちていく。これ、経験ある人多いんじゃないかな。GSDの解決策はシンプルで賢い。大きなタスクを小さな計画に自動分割各計画をフレッシュなコンテキストで実行タスクごとにgitコミットを自動作成つまり**「区切りをつけてリフレッシュする」を自動化**してくれる。長時間の開発セッションでも品質を維持できるようになる。最新版のGSD 2はさらに進化して、コンテキストのクリア、コスト追跡、スタックループの検知、クラッシュからの復帰まで全自動。Claude Code以外にもGemini CLIやCodexにも対応してる。4. clone-website — URLひとつでサイトを丸ごと再現GitHub: https://github.com/JCodesMore/ai-website-cloner-templateスター数: 2,400+（公開数日で）カテゴリ: スキルこれはXでテツメモ氏が詳しく解説して375いいね付いたやつ。URLをひとつ指定するだけで、そのWebサイトを丸ごと再現する。しかも単なるコピーじゃない。仕組みがえぐい。偵察: Chrome MCP経由でサイトを完全検査。スクロール、クリック、ホバー、スマホ表示まで全部チェック設計図作成: 各パーツの仕様書を自動生成（CSSの数値、ホバー時の動き、レスポンシブ対応まで）並列ビルド: パーツごとに別々のAIエージェントが同時に動く自動マージ: 全パーツを1つのサイトに組み上げて品質チェック特に3番目の「並列ビルド」が革命的。従来は1つずつ作ってたのが、複数のエージェントが同時に建てる。Web制作の時間コストが根本から変わる。5. n8n-MCP — ノーコード自動化とClaude Codeの融合GitHub: https://github.com/czlonkowski/n8n-mcpカテゴリ: MCPサーバーn8n（エヌエイトエヌ）は、ノーコードでワークフロー自動化ができるオープンソースツール。これをClaude Codeから直接操作できるようにするMCPサーバー。何がいいかというと、自然言語で「こういう自動化作って」って言うだけでn8nのワークフローが完成する。1,396のn8nノードに関する深い知識を持っている「Slackに通知して、スプシに記録して、メール送って」みたいな複雑なフローも一発n8n-skillsと組み合わせると7つの補完スキルも使えるエンジニアじゃなくても、業務の自動化がClaude Codeとの会話だけで実現できる。6. Google Workspace CLI — Gmail・カレンダー・ドキュメントを全部操作GitHub: https://github.com/googleworkspace/cliカテゴリ: CLI + スキルGoogle公式のCLIツール。Gmail、Drive、Calendar、Sheets、Docs、Chatを1つのコマンドラインから操作できる。しかも92のAIエージェント用スキルが同梱されてるから、Claude Codeからすぐ使える。活用例を挙げると。「今日のメール確認して、重要なやつだけ教えて」「来週の空き時間にミーティングを設定して」「このスプレッドシートのデータを分析して」MCP不要で、BashツールでそのままGoogle Workspaceを操作できるのがポイント。Google Workspace使ってる人は入れて損なし。7. Awesome Claude Code Toolkit — 全部入りの宝箱GitHub: https://github.com/hesreallyhim/awesome-claude-codeカテゴリ: キュレーションリスト2026年2月にGitHub Trendingで1位を獲得した、最も包括的なClaude Codeツールキット。中身がとんでもない。135のエージェント35のキュレーション済みスキル（SkillKit経由で40万+）42のカスタムコマンド150以上のプラグイン19のフック、15のルール、7のテンプレート、8つのMCP設定「何を入れればいいかわからない」って人は、まずこのリポジトリを見るのがおすすめ。ジャンル別に整理されてるから、自分に合ったものを見つけやすい。8. UI UX Pro Max — バイブコーディングのUI品質を爆上げGitHub: https://github.com/nextlevelbuilder/ui-ux-pro-max-skillカテゴリ: スキル「AIにコード書かせたけど、見た目がダサい…」って経験ない？UI UX Pro Maxは、プロ級のUI/UXデザインの知識をClaude Codeにインストールするスキル。入れるだけで、生成されるUIの品質が明らかに変わる。バイブコーディング（自然言語でアプリを作る手法）をやってる人には特に刺さると思う。9. Obsidian Skills — 「第二の脳」をClaude Codeと連携GitHub: https://github.com/kepano/obsidian-skillsカテゴリ: スキルObsidian（メモアプリ）のCEO本人が作ったスキル。自分のナレッジベースをClaude Codeから参照・操作できるようになる。普段Obsidianでメモやドキュメントを管理してる人にとっては、自分の知識とAIの能力が融合する感覚を味わえる。10. GitNexus — コードベースを知識グラフ化GitHub: https://github.com/abhigyanpatwari/GitNexusカテゴリ: ツール大規模なコードベースの全体構造を、ブラウザ上で知識グラフとして可視化できるツール。「このプロジェクト、どこから手をつければいいの？」って時に、コードの依存関係や構造が一目でわかる。新しいプロジェクトに参加した時とか、レガシーコードを理解したい時に重宝する。結局、まず何を入れればいい？10個紹介したけど、「全部入れるのは大変…」って思った人向けに、優先度をまとめておく。まず入れるべき3つSuperpowers: これだけでClaude Codeの使い方が根本的に変わるClaude-Mem: セッション間の引き継ぎが自動化されて効率爆上がりGSD: 長時間の作業でも品質が落ちなくなる用途に応じて追加Web制作してるなら → clone-website業務自動化したいなら → n8n-MCP + Google Workspace CLIバイブコーディングやってるなら → UI UX Pro Max自分もflowstateっていうコンテンツ生成パイプラインをClaude Codeで構築してるけど、.claudeフォルダを育てていく感覚はマジで大事。CLAUDE.md → skills → hooks → pluginsの順番で少しずつ拡張していくのがおすすめ。1個入れるだけでも全然違うから、まずはSuperpowersから試してみて。この記事が参考になったら、いいねやフォローしてもらえると嬉しい。Claude Codeの活用法は今後もどんどん発信していく予定。
