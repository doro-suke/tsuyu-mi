## 本文
この記事でやること
Claude Codeに頼んで、セリフ・音つきの30秒ショート動画を作ります。 プロンプト(依頼文)はすべてコピペできる形で載せているので、上から順に進めれば同じようなものが作れます。
そして最後には、こうなります。
テーマ: 閉店後のラーメン屋台で、店主がこっそり隠しメニューを試作する
予算は $10 以内。あとはお任せします。
テーマを一言伝えるだけで、絵コンテ→画像→動画→編集まで全自動。 これがこの記事のゴールです。

使うものはシンプルです。


Claude Code — 全体の監督役。コードを書き、APIを呼び、編集までやる

Gemini API — 画像は Nano Banana Pro、動画は Gemini Omni。APIキーは1つで両方使えます


ffmpeg — 動画をつなぐ定番ツール

スクリプトはすべて Node.js(公式SDK @google/genai) で作らせます[1]。


 1. 仕組み — Claude Codeが監督、Geminiが撮影スタジオ
先に大事な事実をひとつ。Claude自身は、画像や動画を作れません。 得意なのは、コードを書く・調べる・ファイルを操作すること。だから絵と映像はGoogleの生成AIに作らせて、Claude Codeにはそれらを呼び出すスクリプトを書いて実行する「監督」をやってもらいます。



役割
担当
やること

作画

キャラの設定画・絵コンテのイメージ画を描く

もうひとつの大事な事実。この記事で使うGemini Omniが1回の生成で作れるのは、10秒までの「1カット」です(1回で30秒を生成できるモデルも出はじめましたが、まだ一部です[2])。だから 6秒のカットを5本作って、つないで30秒にする — 映像制作と同じ「カットを撮って編集する」流れになります。ここにClaude Codeが効きます。カットの管理もつなぎもぜんぶやってくれるからです。


 2. 準備

 2-1. Claude Code
インストールとログインは公式手順どおりで。この記事はターミナルで claude と打てば起動する状態から始めます。Claudeの有料プラン(Pro / Max など)が必要なので、そこだけ先に用意してください。

 2-2. Node.js と ffmpeg をインストール
Node.js は生成スクリプトを動かすのに使います。以前はClaude Code自体がNode.jsを必要としましたが、いまは推奨のインストール方法がNode.js不要のネイティブ版になったので、入っていないことがあります。node -v で確認して、バージョンが出なければ公式サイトのLTS版を入れてください。
ffmpeg は動画の連結・音量調整に使います。
# macOS (Homebrew)
brew install ffmpeg

# Windows (winget。候補が複数出て止まるのでIDを指定する)
winget install -e --id Gyan.FFmpeg

# Ubuntu / Debian
sudo apt install ffmpeg
ffmpeg -version が表示されればOKです。

 2-3. Gemini APIキーを作る(お金の安全設定つき)
APIキーは、Claude CodeがあなたのかわりにGeminiを呼び出すための「合鍵」です。


Google AI Studio にGoogleアカウントでログイン
鍵マーク🔑の「Get API key」→「API キーを作成」でキーを発行し、コピーして控える
この記事で使う画像・動画のモデルはどちらも無料枠の対象外なので、支払い方法を設定する



 2-4. APIキーを環境変数に設定する
発行したキーは、環境変数 GEMINI_API_KEY に設定します。公式SDKはこの名前の環境変数を自動で読むので、スクリプト側の設定は不要。どのフォルダで作業しても同じキーが使えるため、あとで手順を使い回すときも楽です。
# macOS / Linux(zshの場合。bashなら ~/.bashrc)
# ※このやり方だとキーがシェルの履歴にも残ります。気になる場合は
#   エディタで ~/.zshrc を開いて export 行を直接書き足してください
echo 'export GEMINI_API_KEY=発行したキー' >> ~/.zshrc
source ~/.zshrc

# Windows(PowerShell。設定後にターミナルを開き直す)
setx GEMINI_API_KEY "発行したキー"


 3. プロジェクトを作る
作業フォルダを作ります。
mkdir ai-video && cd ai-video
【小ネタ】閉じた環境(devcontainer)で動かす
Claude Codeにコマンドを実行させるのが少し不安、という人向け。devcontainer(使い捨ての作業用コンテナ)の中でClaude Codeを動かすと、コマンドが届く範囲はそのコンテナの中だけになります。ffmpegなどの道具もコンテナ側に入るので、手元のPCを汚さずに済むのもうれしいところ。編集したファイルや生成した動画は、いつもどおり手元のプロジェクトフォルダに出てきます。
1. 道具を入れる
まずDockerをインストールします。定番は Docker Desktop。Macなら OrbStack がおすすめで、軽くて速く、docker コマンドはそのまま使えます。
そのうえで、コンテナを操作する devcontainer CLI を入れます。
npm install -g @devcontainers/cli

2. 設定ファイルを置く
プロジェクトフォルダに .devcontainer/devcontainer.json を作ります。これ1枚で「Claude Code + Node.js + ffmpeg入りのUbuntu」ができあがります。
{
  "name": "ai-video",
  "image": "mcr.microsoft.com/devcontainers/base:ubuntu",
  "features": {
    "ghcr.io/devcontainers/features/common-utils:2": {
      "configureZshAsDefaultShell": true
    },
    "ghcr.io/devcontainers/features/node:1": {},
    "ghcr.io/anthropics/devcontainer-features/claude-code:1": {}
  },
  // ffmpeg は用意された部品が無いので自分で入れる
  "postCreateCommand": "sudo apt-get update && sudo apt-get install -y ffmpeg",
  // 手元の環境変数をコンテナへ渡す(キーの中身はファイルに書かない)
  // containerEnv ではなく remoteEnv にする。イメージに焼き込まれないため
  "remoteEnv": {
    "GEMINI_API_KEY": "${localEnv:GEMINI_API_KEY}"
  },
  "remoteUser": "vscode"
}

3. 起動して入る
プロジェクトフォルダで2つ打つだけです。初回はビルドで数分かかります。
# コンテナを作って起動する
devcontainer up --workspace-folder .

# コンテナの中でClaude Codeを立ち上げる
devcontainer exec --workspace-folder . claude

ここから先は記事の手順そのままです。片付けたくなったら devcontainer down --workspace-folder . で止められます。
知っておくとよいこと


コンテナの中でログインし直しになります。しかもコンテナを作り直すたびに消えるので、残したい場合は公式手順のとおり ~/.claude にボリュームをマウントしてください
コンテナの中なら、承認をいちいち待たずに走らせる --dangerously-skip-permissions も使いやすくなります(9章の全自動と相性がいい)



 ルールをCLAUDE.mdに書く
Claude Codeを起動する前に、ひとつだけ仕込みをします。ここがこの記事でいちばん効くところです。
チャットで「今後はこうして」と約束しても、次のセッションで守られる保証はありません。毎回守ってほしいことは、会話ではなくファイルに書きます。プロジェクト直下に CLAUDE.md を置くと、Claude Codeは起動のたびに自動で読み込みます。
エディタで次の内容の CLAUDE.md を作って、フォルダ直下に保存してください(そのままコピペでOK)。

CLAUDE.md
# AI動画プロジェクト

## 使う道具
- 生成スクリプトは Node.js + 公式SDK「@google/genai」で書く
- 画像生成は gemini-3-pro-image(Nano Banana Pro)、
  動画生成は gemini-omni-flash-preview(Gemini Omni)をモデル名で明示的に指定する。
  勝手に別のモデルに切り替えない
- 動画の連結・音量調整・フレーム抽出は ffmpeg を使う
- APIキーは環境変数 GEMINI_API_KEY から読む。
  キーの中身をファイルに書き込んだり、画面に表示したりしない

## お金のルール
- 課金が発生する生成の前に必ず止まる。「何を・何枚(何秒)・いくらか」の
  見積りを見せて、私が OK と言ってから実行する
- 生成が失敗したように見えても、すぐ作り直さない。通信が切れただけで
  生成自体は成功していることがあるので、まず結果が残っていないか取りに行く
- 作り直しは同じ内容につき2回まで。超えたら止まって相談する

## 確認のしかた
- 画像や動画の確認は、確認用ページ「check.html」を作ってブラウザで開く
- check.html は1枚だけ。確認のたびに新しいHTMLを作らず、
  工程の節目ごとに同じファイルへ節を追記していく。
  過去の節(採用した画像・OKした見積り)は消さずに残す

モデル名まで書くのには理由があります。指定しないと勝手に簡易モデルが選ばれて画質が落ちることがあり、さらに曖昧に「画像を作って」と頼むと、絵が描けないClaudeがSVG(図形の組み合わせ)で「それっぽい絵」を自作してしまう事故すら起きます。モデル名の名指しで両方防げます。
「check.html」は確認用のWebページです。生成した画像や動画を1枚ずつ開いて見比べるのは大変なので、ブラウザで1ページ開けば全部確認できる状態をClaude Codeに毎回作らせます。次の章から、頼まなくても勝手に出てくるようになります。

 Claude Codeを起動する
ファイルを置いたら、このフォルダでClaude Codeを起動します。
claude
起動時に CLAUDE.md が自動で読み込まれ、いま書いたルールを知った状態で会話が始まります。

 4. はじめての1本(10秒・約150円)
準備ができたので、まず1本作ってみましょう。せっかくなので、実写では絶対に撮れない画を。
Gemini Omniで、10秒の動画を1本作りたいです。
APIキーは環境変数 GEMINI_API_KEY に設定済みです。

内容: 夜の大都市の上空を、巨大なクジラがゆっくり泳いでいく。
ビル群のネオンが濡れた巨体に反射し、尾びれが雲をかき分ける。
街のざわめきと、遠くに響くクジラの声。縦型(9:16)。

CLAUDE.mdのルール通り、生成の前に見積りを見せてください。
送信すると、Claude Codeが @google/genai の使い方を調べ、生成スクリプトを書き、「何を・何秒・いくらかかるか」の見積りを見せてOKを求めてきます。金額(10秒なら$1.00ほど)を確認して「OK」と返せば生成開始。数分待つと、フォルダに動画ファイルができています(ファイル名はClaude Codeが付けるので、けっこう長い名前になります)。ネオンの街の上をクジラが泳ぎ、音も入っています。
そして頼まなくても、check.html を作って確認できるようにしてくれます。CLAUDE.mdに書いたルールが、さっそく効いています。


 5. キャラクターシートを作る
ここから30秒動画に向けた本番です。動画AIの最大の弱点は、何も工夫しないとキャラの顔がカットごとに別人になること。対策は「キャラクターシート」を先に作り、毎回の生成に添えることです。中身は2つ。


設定の文章 — 名前・外見・性格。毎回添える「変わらない説明文」

参照画像 — 顔アップと全身の静止画。AIに見せる「この人を出して」のお手本

主役はこの方にお願いします。
オリジナルキャラクターを1体作って、キャラクターシートを整えてください。

キャラ案: 夜の路地裏にだけ現れる屋台ラーメン「ねこ軒」の店主、貫禄のある三毛猫。
ねじり鉢巻きに藍色の作務衣、首に豆絞りの手ぬぐい。
無口な職人気質だが、一杯出すときだけ低い声で「へい、お待ち」と言う。

やってほしいこと:
1. 設定の文章(外見・性格・口ぐせ)を character.md にまとめる
2. 参照画像を作る: まず顔のアップを1枚。次にその顔アップを参照画像にして、
   同一個体の全身(正面)を1枚。画像生成は gemini-3-pro-image で
3. いつも通り、生成前に枚数と費用の見積りを見せてください
ここでも見積りが出て止まります。静止画は1枚$0.134(1K・2K)、2枚で40円ほど[3]。「OK」と返して初めて生成が始まります。 これ以降も、課金の前には毎回こうして止まります。内容と金額を確かめて「OK」と返す — その繰り返しです。

 できた画像は自分の目で確認する
生成が終わると、Claude Codeが check.html に「キャラ確認」の節を作ってくれます(CLAUDE.mdのルールです)。参照画像2枚と、character.md の設定の要点が1ページに並ぶので、check.html を開いて確認します。
「設定も check.html に書けば character.md は要らないのでは?」と思うかもしれませんが、役割が違います。character.md は生成のたびにAIへ渡す「素材」、check.html はあなたが見る「確認ページ」です。素材は毎回プロンプトに埋め込まれるのでテキストファイルのほうが扱いやすく、確認ページにはその要点が転記されます。あなたが開くのは check.html だけでOKです。
ページの2枚を見比べます。地味ですが、この「自分の目で確かめる」がAI動画づくりの実力そのものです。見るのは4点。


指定どおりか — 三毛柄・ねじり鉢巻き・藍色の作務衣・豆絞りが全部入っているか

顔アップと全身が同じ猫に見えるか — 三毛柄の模様までズレていないか。ここが崩れると動画でも顔が安定しない

破綻がないか — 前脚やヒゲ、作務衣の構造がおかしくないか。疑わしい部分は拡大して見る

余計なものがないか — 頼んでいない文字・ロゴ・透かし(屋台の看板に謎の文字、はよくあります)

気になったら遠慮なく作り直します(1枚数十円です)。
全身画像の作り直しをお願いします。顔は完璧ですが、作務衣の藍色が黒に見えます。
「藍色の作務衣」を強調して、顔アップと同じ三毛柄のまま、もう1枚。
生成の前に、いつも通り見積りを見せてください。

 6. 絵コンテを作る
いきなり動画を生成せず、絵コンテ(カット割りの設計図)を先に作ります。映画やCMと同じ段取りです。これをやると無駄な生成=無駄なお金が激減します。静止画の作り直しは1枚$0.134、動画の作り直しは1カット$1前後 — 7倍以上の差があるからです。
このキャラで30秒のショート動画を作りたいです。まず絵コンテを作ってください。

テーマ: 雨の夜、路地裏にぽつんと明かりを灯す屋台ラーメン「ねこ軒」。
店主の仕込みから、湯気の立つ一杯を差し出す「へい、お待ち」まで。
形式: 6秒×5カット、縦型(9:16)

やってほしいこと:
1. 各カットの「内容・カメラ(寄り/引き)・セリフ」を表にして見せる
2. 表に私がOKを出したら、カットごとのイメージ画(静止画)を
   cut-01.png 〜 cut-05.png として gemini-3-pro-image で1枚ずつ作る。
   毎回、character.md の設定と参照画像を添えること
3. いつも通り、画像を作る前に費用見積りを見せてください
まずカット割りの表だけが返ってきます。あとは確認が出るたびに「OK」と返して進めていきます。
できあがると check.html に「絵コンテ」の節が増え、5枚のイメージ画がカット番号・内容・セリフつきで並びます。話の流れは通っているか、全カット同じ猫か、寄りと引きが混ざっているか — 気になるところがあれば、そのカットだけ直してもらいます。
カット3だけ作り直してください。ほかのカットと別の猫に見えます。

 7. 30秒動画に組み立てる
絵コンテが確定したら、いよいよ動画です。
絵コンテが確定したので、動画にしていきましょう。

・カット1から順に、1カットずつ Gemini Omni で生成してください
・各カットとも、character.md +参照画像+そのカットの絵コンテを毎回添えること
・画像は役割を書き分けて渡すこと。絵コンテのイメージ画は「最初のコマ」、
  キャラ参照画像は「画面に出さない見た目のお手本」
・服装や小物は「藍色の作務衣」のように色まで毎カットの指示に書くこと
・全カット分の費用見積りを check.html の「見積り」の節に出して、私のOK後に開始
・全カットできたら ffmpeg で1本につなぎ、全体の音量をそろえて
  SNSで聞きやすい音量に調整してください
・完成したら check.html に「完成確認」の節を追記:
  全カットと完成版をその場で再生できるプレイヤー+
  実際に生成した秒数・枚数と、そこから計算した費用
ポイントは「毎カット、シートと参照画像を全部添え直す」こと。動画AIは前のカットのことを覚えていないので、「さっきと同じキャラで」は通じません。カット間で何かズレたら、原因はほぼ「そのカットに書き忘れた」です。
役割の書き分けも同じくらい効きます。絵コンテのイメージ画とキャラ参照画像は、渡し方は同じでもやってほしいことが正反対です。前者は「この絵から動き出してほしい」、後者は「画面には出さず見た目だけ合わせてほしい」。ここを言わずに2枚並べて渡すと、AIがどちらの役かを推測します[4]。推測が外れると、絵コンテで決めた構図が丸ごと無視される、という形で出ます。
生成が終わったら、check.html の「完成確認」の節で必ず全カットを自分の目で再生して確認します。


顔 — カットごとに別猫になっていないか。三毛柄の模様は同じか

服・小物 — 作務衣や手ぬぐいの色が途中で変わっていないか(本当によく起きます)

文字 — 頼んでいない字幕・ロゴが画面に焼き込まれていないか(画面のすみずみまで)

おかしいカットがあったら「カット3だけ、◯◯を直して作り直して」と部分的に頼めばOK。全部作り直す必要はありません。
過去の節を消さずに積んでいくルールもここで効いてきます。採用した参照画像もOKした見積りも同じページに残っているので、check.htmlがそのまま制作記録になります。


 8. ナレッジをためて、CLAUDE.mdを育てる
もうひとつ、続けるほど楽になる仕組みを入れます。「今日わかったこと」を記録させておくと、次回はその記録を読むだけで同じ失敗を繰り返さなくなります。
このプロジェクトの運用を整えます。

1. knowledge フォルダを作り、次の2ファイルで記録を始めてください
   ・learnings.md — うまくいったこと/失敗と原因/次はこうする(日付つき)
   ・costs.md — 制作ごとの費用の実績
2. CLAUDE.md に次のルールを追記してください
   ・作業を始めるときは、必ず最初に knowledge フォルダを読む
   ・動画1本ごとに専用フォルダを作り、その動画のファイル
     (画像・カット・完成版・check.html)はすべてその中にまとめる
   ・作業の節目で learnings.md と costs.md に自分で追記する

追記できたら CLAUDE.md を見せてください。私が読んで理解できることも大事なので。
これで、いままで毎回頼んでいたことは、もう頼まなくても守られるようになりました。次にこのフォルダで claude を起動したときのClaude Codeは、最初からあなたのルールと過去の学びを知った状態で仕事を始めます。

 9. 仕上げ — ワンプロンプトで全自動
いまのフォルダにはキャラクターシート・CLAUDE.mdのルール・knowledgeの学びがそろっています。つまり、工程全体をまるごと1つの依頼で任せられる状態です。
ポイントはひとつだけ。工程ごとのOKの代わりに、「予算の上限」を先に渡すこと。
今日は1本まるごとお任せします。

テーマ: 閉店後の「ねこ軒」。店主がこっそり隠しメニューを試作して、
自分でスープを味見して、思わずヒゲが上がる

 10. 他の生成AIも「同じ型」で使える
この記事はGemini APIひとつで完結しましたが、この型はGemini専用ではありません。新しいサービスのAPIキーを環境変数に足して「このAPIを使って」と頼むだけで、同じ工程に組み込めます。接続コードはClaude Codeが書いてくれるので、あなたの作業はキーの発行だけ。キャラクターシートも絵コンテも check.html もそのまま通用します。
たとえば、以下などがあります(単価・仕様は2026-08時点。使う前に必ず公式の料金ページを確認してください)。

 Veo 3.1(Google・動画)
画質が足りなくなったら。 Gemini Omniと同じ GEMINI_API_KEY で使える高画質枠で、キーの追加すら不要です。720p/1080p/4Kに対応し、実写調の質感に強い。1回の生成は8秒ですが、7秒ずつ継ぎ足して長くしていく延長機能があります。ただし単価はGemini Omni($0.10/秒)の4〜6倍 — 全カットVeoは高くつくので、最終出力の「ここぞ」のカットに使うのが現実的です(速度重視のFast、さらに安いLiteもあります)。

 Grok Imagine(xAI・動画/画像)
本数を回したくなったら。 単価が安く(480pで$0.05/秒〜、上位のGrok Imagine Video 1.5でも$0.08/秒)、生成も速い。画像→動画(i2v)が得意で、絵コンテのイメージ画をそのまま動かす用途と相性がいいです。Gemini Omniには生成回数の上限があり(枠はプランや利用状況で変わります)、上限に当たった日の保険としても優秀です。静止画生成も1枚数円〜十数円と激安で、候補を大量に出して選ぶ物量戦向き。弱点は、頼んでいない文字を勝手に描き込む癖。

 Kling(快手・動画)
セリフをきっちり喋らせたくなったら。 口パク(リップシンク)の本命です。最新のKling 3.0ではテキストからリップシンク済みの音声ごと生成でき(多言語対応)、以前のように「音声ファイルを別に用意して口を合わせる」2段構えを組まなくてもよくなりました。カットをつないで語る機能や、短い動画から被写体と声を写し取る上位モデル(3.0 Omni)もあります。2人が同時に会話するシーンにも強いです。

 Seedance(ByteDance・動画)
細かく制御したくなったら。 参照素材を大量に渡せるのが特徴の制御派向けモデルです。Seedance 2.5は参照入力を最大50点まとめて渡せる(画像30・動画10・音声10)うえ、1回で最長30秒の生成に対応しています(2026-07-31発表)。ただしAPIはまだ提供されていません — 料金表とモデルIDは先に公開されているので近日中と見られますが、使えるかどうかは公式で確認してください。

 gpt-image-2(OpenAI・画像)
画像に文字を出したくなったら。 「文字を正確に出す」「文字を出さない」の両方で最強クラスで、図解やサムネイル向き。写実の質感はGemini系(Nano Banana Pro)が優位なので、使い分けです。

 Eleven Music / Eleven v3(ElevenLabs・音楽/音声合成)
BGMやナレーションが欲しくなったら。 音楽は Eleven Music で、秒数を指定してインスト曲を生成できます。ナレーションは音声合成の Eleven v3 など。料金はクレジット制でプランによって実効単価が変わるので、公式で確認してください。ちなみにGemini Omniの動画には環境音・セリフが最初から入っているので、BGMなしでも1本として成立はします。

 Higgsfield(いろいろまとめて使えるプラットフォーム)
キーを足していくのが面倒になったら。 Kling・Seedance・Veo などいろんなモデルを1つのアカウントでまとめて使えるプラットフォームもあります。MCPとCLIが公式に用意されていて、APIキーなしでClaude Codeから使えるとのこと。 課金はAPIの従量課金ではなくクレジット制のようです。

 MiniMax H3(MiniMax・動画)
1本いくら、から降りたくなったら。 ここまでのモデルはすべて「相手のサーバーにお願いする」形でしたが、動画モデルにはオープンウェイトのものもあります。
ウェイト(重み)は、学習の結果できあがった数値のかたまり — AIの中身そのものです。GeminiやVeoはこれが非公開なので、APIを通じて向こうのサーバーで動かしてもらうしかありません。オープンウェイトのモデルはこの中身をダウンロードできるので、自分のPCで動かせます。生成そのものの課金はゼロ、かかるのは電気代だけ。素材が外に出ない(未公開の企画や社外秘でも安心)、サービス終了や値上げに振り回されない、というのも効いてきます。
ただしオープンソースとは別物です。公開されるのは「できあがった中身」だけで、学習データや作り方までは出ないのが普通。使い道にも独自の条件が付くことがあるので、ライセンスは必ず確認してください。
そのひとつが、2026年8月に公開された MiniMax H3(Hailuo 3.0)。映像と音声を一度に出すつくりがGemini Omniと似ていて、最長15秒・2Kまで対応します。公開されたその日から、ComfyUI(手元でAI生成を動かすための定番ツール)で使えるようになりました。
必要なマシンは、ざっくり VRAM 24〜32GB(RTX 4090 / 5090クラス)あれば現実的、という水準です。ComfyUI側の最適化がかなり効いているので、12〜16GBでも動くらしいです。ディスクは40GB強。
性能の良いローカルマシンがなければ、GPUを借りればOK。 RunPod のようなGPUクラウドなら、この構成を時間貸しで用意できます。数十万円のグラフィックボードを買わずに、必要なときだけ上位GPUを借りる形です。


 おわりに
正直なところ、クオリティは「そこそこ」です。 絵コンテどおりに出ないカットは毎回いくつか混じります。指定した構図が無視される、左右が反転する、消えているはずの明かりが灯っている、書いた覚えのない文字が入る — 細かい指示はこぼれる前提で見たほうがいいです。テレビCMや作品として世に出せるかというと、まだそこまでではありません。
一方で、SNSに1本上げる・企画のイメージを社内で見せる・お店の紹介を作る、あたりの用途なら十分通ります。
最後に、いくつか補足を。


画像生成はサブスクで済ませる手も — ChatGPTの有料プランを契約しているなら、Codex CLIに画像生成(gpt-image-2)が組み込まれています。ターミナルから直接作れるので、キャラ参照や絵コンテの静止画をそちらで用意すれば、その分のAPI課金はゼロです。できた画像をフォルダに置けば、あとの工程はこの記事のままで通ります。ただし同じ gpt-image-2 でも、APIとして呼ぶと完全に別契約・別課金です。ChatGPTの有料プランに入っていてもそちらは使い放題にならず、OpenAI Platform 側への支払いが別に発生します

Pythonでも作れます — Node.jsにしたのは環境の説明を簡単にするためです。Pythonが使える環境なら、CLAUDE.mdの1行を書き換えるだけでPython版になります

「カットをつなぐ」が唯一の道でもなくなりつつある — Seedance 2.5は1回で最長30秒の生成を発表しました。ただし、カット割りで考える段取り自体は、一発生成の時代になっても構成の道具として残ります

動画生成AIを使わずに動画を作る道もあります — 静止画にゆっくりズームやパンをつけてffmpegでつなぐ方法と、Claude Codeの得意分野であるHTML/CSSでアニメーションを作らせて動画に書き出す方法です(書き出しの仕組みもClaude Codeが自分で用意します)。どちらも動画生成の課金はかからず、画面内の文字も生成AIに描かせるより確実。解説系ならこれで十分なことも多く、タイトルや図解のカットだけこの手で作って混ぜる合わせ技も効きます

動画素材があるなら、生成すら要りません — 撮影済み素材の切り出し・連結・テロップ・音量調整だけをClaude Codeに任せる使い方もあります。この記事の型はそのまま通用します
