## 本文
こんにちわ!山ちゃんです。
がむしゃらに技術キャッチアップしてた私の勉強法が変わってきた話です。

 結論！！
自分の時間も脳のキャパも有限。だから何でもかんでも深くは追えません。
じゃあどうするか？


…とはいえ、この学習スタイルが成立するようになったのはここ数年の変化があるからです。

 "調べるコスト"が激減した時代
かつては「調べる」こと自体がコスト高でした。書籍・公式ドキュメント・Stack Overflow を渡り歩いてやっと答えにたどり着く。だから知識を自分の頭に溜め込むことに価値がありました。
今は違います。AIによって "調べるコスト"が激減 し、"インデックス"さえ持っていれば、深い中身もAIと壁打ちしながら数分で要点まで引き出せる。さらにハルシネーション率が下がってきたことで引き出した知識をそのまま実務の足場にできる度合いも以前より増しています。「インデックス＋AIで引き出す」戦法が、絵に描いた餅ではなく現実的に回るようになってきました。


 "資格マニア"だった私
これまでの私はとにかく資格を取りまくってスキルを積むタイプでした。
でも最近、特にAI系の資格は技術の進化に追いつけず取った頃には中身が古い。
サービスも移り変わりが速く、深く理解した頃にはもうブームが過ぎている。
そんなとき出会ったのが Claude Code の Skills。「人間の学習もこれでいい」と思い始めました。

 Skillsの「段階的開示」とは
Claude Code の Skills は、知識を最初から全部は読み込まない仕組みです。
各 Skill には「名前」と「短い説明（description）」だけが常にAIのコンテキストに乗っています。「このトピックが来たらこの Skill を使え」という一行のインデックスだけを軽く持ち続け、詳しい手順（本体）は必要と判断した瞬間にはじめて読み込まれます。さらに本体から参照される追加ドキュメントは、本当に要るときだけ開かれる。重い本体を必要になるまで読まない、という progressive disclosure（段階的開示） の構造です。

 人間にも同じことができる
この構造を人間の学習に転用します。インデックスだけ広く持っておけばいい。
深い知識は必要になったとき取りに行く。
知識の深さは、4段階で考えると分かりやすいです。



レベル

Lv0. 驚き屋
ニュースに「すごい！」と沸くだけ。中身を言えない

Lv1. 概要把握
概要を一読し "何ができるか" を自分の言葉で言える

Lv2. 詳細把握

Lv3. 自己体験
実際に手を動かして使い、自分の血肉になった
本当に必要なものだけ





 「全部インデックスでいい」わけじゃない——核は深く積む
ここで大事な但し書きを...何もかもをインデックスで済ませると破綻します。深く積むべきものと、インデックスで足りるものは別物だからです。


核（コア）= 深く積み続ける：自分の主戦言語、データ構造、ネットワーク、DB、トランザクション、設計の型、デバッグ力。変化が遅く・レバレッジが高く・あとから一夜漬けが効かない領域です。そして決定的なのは、この深さがあるからこそ AI に的確な問いを立てられ、返ってきた答え（とハルシネーション）の良し悪しを判定できること。核が無いといざ深掘りしてもAIの嘘を見抜けず、さっき言った「裏取り」自体が機能しません。

周辺 = インデックスで十分・深掘りは遅延：今週話題のツール、新しいマネージドサービス、流行りのフレームワーク、隣接ドメイン。陳腐化が速く、先に深く積む ROI が最悪な領域です。"資格マニア"だった私が空振りしていたのは、まさにこの周辺を核と同じ熱量で積もうとしていたからでした。




 Skillとの決定的な違い——人間に"即ロード"はできない
ここで一度、Skill（マシン）と人間の違いに正直に向き合っておきます。
Skill（マシン）と人間の"ロード"の違い
Skill はトリガーされた瞬間に本体をサクッとロードして、即・完全に使える状態になります。ミリ秒レベルで。これがマシンの強さです。
翻って人間には「本体を即ロード」するスイッチはありません。どれだけ Lv1 のインデックスを広く持っていても、必要になった瞬間にLv3の深度で使えるわけじゃない。人間版の"本体ロード"は、理解して→手を動かして→体で覚えていく、という地道なプロセスです。マシンが一瞬でロードするのを横目に、こちらはAIでブーストしつつ気合いでなんとかする——それが現実です。(根性論)


 浅い知識の仕込み
Lv1のインデックスは、日頃から薄く広く集めておきます。私がやっているのは主にこの3つ——「人 → 自分の主戦場 → 業界全体」とズームアウトしていく3層です。


人をウォッチする（最も鮮度が高い層）… 自分が信頼する発信者を SNS でフォローし、通知をONにしておく。アルゴリズムに任せず、人を起点に情報を取りに行く

自分の主戦サービスを追う（自分ごとの層）… 普段使っているサービスのアップデート情報を、RSSを毎朝自動で集めてAIに要約させ、手元に通知が届くようにしている

業界全体をざっくり拾う（広角の層）… 特定のニュースサイトの更新を同じようにRSSで自動収集し、AIに要約させて毎朝流し読みする

どれも深追いはしません。ただし気になった話題は1〜2回AIと壁打ちして「これは何ができる技術なのか」を自分の言葉で言えるところまで持っていく。それがLv1のインデックスです。「なんとなく知っている」止まりではインデックスにならない、という基準だけ持っておくと良いです。”驚き屋”になってはいけません。

 打ち合わせでの立ち回り
この学習法が実務で聞く例としてお客さんとの打ち合わせ が挙げられます。


会議中 … 「これできます？」と聞かれたら、まず Lv1 のインデックスをもとに「おそらく〇〇で実現できると思います」と返す。その場でAIに調べさせて確証が取れれば踏み込み、無理なら「正確なところは次回までに詰めます」で繋ぐ。ここは 技術力より会議スキル・営業力 が問われる場面。同じ「たぶんできます」でも言い回しや雰囲気で相手の安心感は変わるし、この さじ加減はAIには代われません。


次回まで … AIをフル稼働させてその分野を Lv3 まで引き上げる。AIと壁打ちして、コードを書いて、動かして、詰まって、また聞いて——を繰り返すだけの泥臭い作業です。でもこの反復こそが Lv3（自分の血肉）への唯一の道で、ここもどんなにAIが賢くなっても代わってもらえません。
