## 本文
Codex で弾幕シューティングゲームの生成を試したのでまとめました。1. 前準備(1) Codex のゲーム開発用スキルの準備・Game Studio・Image Gen(2) ゲーム指示の素材の準備。・game.png・bom.png・bg.pngGPT Image 2で背景を分離した時、弾などゴミが残ること多かったので、PhotoShopの生成塗り潰しでゴミを消してから渡してます。(3) 弾幕についての説明の準備。2. ゲーム生成(1) ゲーム生成の指示。添付画像を元に弾幕シューティングゲームを作成してください。アルファブレンドで派手な演出。・game.png : ゲーム画面のスクリーンショット・bg.png : 背景Vite + TypeScript + Phaser。9:16。プレイヤーの弾は戦闘開始してから自動連射。方向キーで移動、シフトキーで移動量1/4、スペースキーでBOM。BOMは現在表示されてる弾幕の一掃。BOMでをカットインを表示。自機の当たり判定は小さくキャラクター絵の中央の丸くアルファブレンドで表示。最初はボスはいなくて、上からでてきてから　FIGHT!の表示で戦闘開始。弾幕のパターンは、HPの残量に応じて4パターン変化。弾幕はどんどん派手になる。敵の弾は中央が白で周囲にアルファブレンディング。当たり判定は中央の白部分のみ。以下の画像が生成されました。(2) プレイヤーキャラの調整。プレイヤーキャラに隠れて敵の弾が見えません。プレイヤーキャラの上に敵の弾を表示して。プレイヤーの弾で敵の弾が見えなくならないように、敵の弾の方を上に表示。プレイヤーキャラのサイズを1/2。プレイヤーキャラの当たり判定をもっと見やすく。プレイヤーキャラの当たり判定をプレイヤーキャラの首あたりに。BOMでボスにダメージはあたえないで。弾を消すだけにして。自機に弾があたっても、周りの弾は消えず、自機のリスタート時は点滅して一定時間無敵になる。(3) ボスキャラの調整。参照画像をもとにしつつも、ボスっぽいデザインにしてください。SFっぽい世界観でおねがいします。(4) UIの調整。スコア、敵体力、ライフ数、BOX数の表示がUIより若干下です。調整してライフとBOMの文字が右にずれてます。ボス体力のバーが初期値でMAX超えてますライフの文字列を1文字分左へ(5) ステージクリア演出の調整。ボス勝利時、ボスの周りにアルファブレンドでたくさんの爆発が怒った後、小さくなりながらフェードアウトすることで落下を演出。背景が高速スクロールした後、プレイヤーが画面上に消えていき、　STAGE CLEARを表示。STAGE CLEARは $imagegen で生成ボスを倒す演出を見たいのでボスの体力を5%からはじめて。ボス倒すと爆発演出なく固まります。自機がSTAGE CLEARより前に表示されるので後ろにして。自機が上に消えていくのは、STAGE CLEARが表示される直前にして。ボスの体力を100%に戻す。(6) ゲームオーバー演出の調整。ゲームオーバー時に GAMEOVER を表示。GAMEOVERは $imagegen で生成自機は消える(7) 弾幕の調整。https://note.com/npaka/n/n5d38b7d84173 を読んで、弾幕のパターンを調整して。体力に応じて4パターン変化をお願いします。全方位弾　↓自機狙い扇弾　↓低速リング　↓螺旋弾最後の螺旋弾をもっと激しく。3. SEとBGMの追加(1) SEとBGMの追加。効果音は「効果音ラボ」、BGMは「Springin’ Sound Stock」で探して、プロジェクトのsoundsフォルダに配置してから、以下を指示します。BGMとSEを追加して。BGM : bgm.mp3自分の弾が敵にあたった時、敵が死んだ時の爆発 : hit.mp3 敵が弾発射した時 : enemy_bullet.mp3BOM発動時 : bom.mp4ステージクリア時 : stageclear.mp3敵の弾が自分にあたった時 : damage.mp34. 動作確認
