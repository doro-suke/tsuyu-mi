## 本文
先日リリースされた Claude Opus 5.5 を触っていて、アニメーションの作り込みがかなり上がっている と感じました。
試したことはシンプルです。
動画生成AI向けに書いた英語プロンプトを、そのまま Opus 5.5 に渡しただけ。
それだけで、コードで描いた約2分10秒の解説アニメーション動画 ができました。

 作ったもの
題材は、今ホットな Jev です。Jev の仕組みを解説するアニメーション動画を Opus 5.5 に作らせてみました。
生成されたフレームのデザインはこんな感じです。


 やり方
やったことは3ステップです。

ChatGPT に「動画生成プロンプトを作らせるための依頼文」を渡す
出力された英語の動画生成プロンプトを受け取る
それを Opus 5.5 に一言添えて渡す


 Step 1: ChatGPT で動画生成プロンプトを作る
いきなり Opus 5.5 に「動画作って」と言うのではなく、先に設計図を作らせます。
ポイントは、ショットごとに「開始時刻・カメラの動き・画面内の動作・次のショットへのつながり」を書かせるテンプレートを渡していることです。これで「スライドを9枚切り替えるだけ」の映像になりにくくなります。
依頼文は以下です。題材（Jev）の部分を差し替えれば、ほかのテーマにも使えるはずです。
動画生成プロンプトを作らせる依頼文（クリックで展開）今話題のJevについて、初心者にも直感的にわかる15秒の解説動画を作りたいです。

以下の「動画生成プロンプトのテンプレート」を使い、Jevを題材にした完成済みの動画生成プロンプトを出力してください。テンプレートの説明や企画案ではなく、動画生成AIへそのままコピー＆ペーストできる全文を出力してください。

## 動画の要件

- 長さは正確に15秒、画角は16:9、全9ショット。
- スタイルは、洗練されたモーショングラフィックス。大胆なキネティックタイポグラフィ、奥行きのある図形、高速かつ滑らかなカメラ移動、気持ちのよい加速と減速を使う。映像全体を「めちゃくちゃかっこいい」と感じる完成度にする。
- 9枚のスライドを切り替える映像にはしない。前のショットで動いた文字・図形・光・線などが次のショットの動きを引き起こす、一続きの映像にする。
- 初心者向けに、「Jevは何をするAIか」を具体例から理解できる内容にする。例として、問い合わせ文「請求が二重です」を入力し、「どの担当に送る？」という質問に対して、あらかじめ用意した「請求・技術・その他」から選ぶ流れを使う。
- Jevは、入力された文章と決められた質問に対し、選択肢・はい／いいえ・点数などの構造化された判断と確率を返すAIとして説明する。Jev自身が長い説明文を執筆したり、映像や画像を直接読み取ったりする描写はしない。
- 確率を画面に数値で表示する場合は、実測値ではなく説明用の架空の例だとわかるようにする。確率は正解の保証として描かない。
- 判断があいまいな場合に人へ回す描写を入れるなら、それはJevの出力を受け取ったアプリ側のルールによる処理として表現する。
- 映像指示は原則として英語で書き、画面に表示する文字とナレーションは日本語のまま正確に記載する。
- 各ショットに開始時刻、カメラの動き、画面内の動作、次のショットへのつながりを記載する。重要な日本語テキストには、読める長さの静止時間を確保する。
- 最後は、主題と結論が読めるエンドカードで締める。画面内の文字が動き続けたまま15秒を迎えない。
- テンプレート内の { } はすべて具体的な指示で埋める。{ } や制作メモを完成版に残さない。
- 出力は「integrated_multimodal_description:」から始め、「overall_soundscape:」「non_diegetic_music:」までを含める。完成した動画生成プロンプト以外の解説は出力しない。
