ゲームの説明文を与えると、AIがGodot Engine 4向けのゲームプロジェクトをほぼ一通り自動で組み立てる「Godogen」が公開されています。Godogenは設計の立案、アート生成、コード記述、実行中ゲームのスクリーンショット取得、見た目や挙動の不具合修正までを一連のパイプラインとして処理し、最終的に実際に動くGodot 4のプロジェクトを出力可能。生成物は2Dと3Dの両方に対応し、一般的なPCでも動かせるとのことです。

htdt/godogen: Claude Code skills that build complete Godot 4 projects from a game description
https://github.com/htdt/godogen

Godot 4は、2Dゲームや3Dゲームを作るためのゲームエンジンで、ゲームをシーンツリーとスクリプトで組み立て、素材や処理をプロジェクトとして整理して扱うことが前提になっています。

Godogenは2つのClaude Code skillsによって全体が進行すると説明されています。1つが計画を担当し、もう1つが実行を担当し、各タスクは新しいコンテキストで実行されるため、役割を絞って処理しやすいように設計されています。出力されるGodot 4プロジェクトは適切なシーンツリー、読みやすいスクリプト、整理されたアセット構成を備えており、単に素材やコードを吐き出すだけではなく、ゲームとしての構造を意識しているのが特徴。

2DアートやテクスチャはGeminiが作成し、必要に応じて選ばれた画像をTripo3Dが3Dモデルへ変換します。また、GDScriptに関しては、LLMがもともと十分に学習できていない部分を補うため、850以上のGodotクラスに対応するカスタムの言語リファレンスや遅延読み込みのAPIドキュメントを用意しているとのこと。


なお、Godogenのコントリビューターであるhtdt氏はClaude Codeを使っている理由について、「検証した範囲では、最も良い結果を出したのはClaude CodeとOpus 4.6の組み合わせで、Sonnet 4.6でも動作するものの、より多くのユーザー側の誘導が必要だった」と語っています。オープンソースのAIコーディングエージェントであるOpenCodeも代替案としてはアリで別の実行環境に変更する余地もあるとしながらも、htdt氏は記事作成時点ではClaude Codeが最善であると述べました。
