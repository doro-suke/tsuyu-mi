## 本文
Gemini in Chrome に「Skills」が登場。ブラウザがAIワークフローの起点になる時代へ
Gemini in Chrome に、AI作業の繰り返しをなくす新機能「Skills」が登場しました。2026年4月14日にGoogleが公式ブログで発表したばかりの機能で、よく使うプロンプトをワンクリックで呼び出せるようになります。
「レシピを見るたびにカロリー計算をお願いしている」「商品ページを開くたびに比較用のプロンプトを打ち込んでいる」——そんな繰り返し作業に心当たりがあるなら、この機能はかなり刺さるはずです。ブラウザ上でのAI活用が、単発の質問応答から「設計済みのワークフロー」へと変わりつつある、そんな転換点となる機能について詳しく見ていきましょう。


Skills in Chrome とは何か

Gemini in Chrome の「繰り返し問題」を解決する
これまでの Gemini in Chrome は、ページをまたぐたびに毎回プロンプトを入力し直す必要がありました。たとえばレシピサイトで食材の代替案を聞く、ECサイトで商品スペックを整理してもらう——便利ではあるけれど、同じようなプロンプトを何度も打ち込む手間は変わらなかったわけです。
Skills は、この「繰り返し入力」の手間をなくすために作られた機能です。チャット履歴から気に入ったプロンプトをそのままスキルとして保存しておき、次回以降はワンクリックで同じ処理を走らせられます。

ブックマークとは何が違うのか
「URL をブックマークするのと何が違うの？」と思うかもしれません。ブックマークが「場所」を保存するのに対して、Skills は「操作」を保存します。保存したスキルは、あらゆるページで実行できます。同じプロンプトを、今日開いたレシピサイトにも、明日比較したい家電の商品ページにも適用できるわけです。


基本的な使い方

プロンプトをスキルとして保存する
使い方はシンプルです。Gemini in Chrome のチャット画面で気に入ったプロンプトが見つかったら、そのまま「スキルとして保存」できます。保存したスキルは、次回から /（スラッシュ）を入力するか + ボタンを押すことで一覧から呼び出せます。あとはスキルを選んで実行するだけです。
編集もいつでも可能なので、使いながら少しずつプロンプトを磨いていくこともできます。

複数タブへの一括適用が便利
Skills の面白いところは、現在開いているページだけでなく、選択した複数タブに対して同時に実行できる点です。たとえば商品を比較したいとき、各メーカーのページを複数タブで開いておけば、スペック比較のスキルを一度実行するだけで、すべてのページから情報を整理してもらえます。

スキルの管理はコンパスアイコンから
保存したスキルは、Gemini in Chrome で / を入力した後にコンパスアイコンをタップすると管理画面に移動できます。サインイン済みの Chrome 端末間で同期されるため、自宅のMacで作ったスキルを会社のWindowsマシンでもそのまま使えます。


スキルライブラリを活用する

「まず試す」なら既製スキルから
Skills の導入でもうひとつ注目したいのが、Googleが用意した「スキルライブラリ」の同時公開です。自分でプロンプトを考えなくても、すぐに使える既製スキルが揃っています。
現時点でライブラリに含まれるスキルの例を挙げると、商品ページを開いたときに成分・原材料を素早くチェックするスキルや、予算と相手の好みを照らし合わせてギフトの選択肢を絞り込むスキルなどがあります。日常的なウェブ閲覧の中で「ちょっと調べたい」と感じる場面に刺さる内容が多いです。

既製スキルをベースに自分流にアレンジ
ライブラリのスキルは、そのまま使うだけでなく編集してカスタマイズできます。「成分チェックのスキルを、アレルギー食材に特化した内容に書き換える」といった使い方ができるので、既製スキルをたたき台として自分の用途に合わせて育てていくのが、個人的には一番おすすめの使い方です。


こんな場面で使ってみよう

ヘルス・ウェルネス
料理レシピのページを開いたとき、「このレシピのタンパク質量を計算して、1食あたりのマクロも教えて」というスキルを走らせるだけで、毎回計算する手間がなくなります。ダイエットや筋トレで食事管理をしている方には特に便利でしょう。

ショッピング・商品比較
家電や日用品を比較するとき、複数の商品ページをタブで並べておいて「スペックを表にまとめて比較して」というスキルを一括実行すれば、手動でメモする作業がなくなります。購入前の情報収集がかなりスムーズになるはずです。

ビジネス・情報収集
長い資料や契約書を開いたとき、「重要なポイントと注意事項だけ抜き出して」というスキルを使えば、全文を読み込む前に概要をつかめます。ニュース記事の要約や、仕様書から要件だけを拾う用途にも応用できます。


セキュリティとプライバシーの設計

Gemini in Chrome と同じ安全基準が適用される
Skills のプロンプトは、通常の Gemini in Chrome と同じセキュリティ・プライバシーの仕組みのうえで動作します。加えて Chrome 自体が備える自動レッドチーミングや自動アップデートによる保護も継続して機能します。

「実行系」アクションには確認が入る
カレンダーへのイベント追加やメール送信など、外部に影響を与えるアクションを伴うスキルを実行する場合は、必ず確認ダイアログが表示されます。スキルを設定しておけば全自動で動く——というわけではなく、ユーザーが最終的な実行を承認する設計になっています。意図しない操作を防ぐ観点から、この確認ステップは重要な安全弁といえます。


まとめ
Skills in Chrome は、「AI に質問する」という一方通行のやりとりを、「設計しておいたフローを実行する」という形に変えていく機能です。自分の使い方に合ったスキルを少しずつ育てていくと、ブラウザでの作業効率がじわじわと上がっていくでしょう。
現時点では Chrome の言語設定を英語（米国）に設定しているMac・Windows・ChromeOS 向けに展開中で、日本語環境への対応は公式情報で確認が必要です。まずは Gemini in Chrome の / コマンドからスキルライブラリを覗いてみるのがいちばん手っ取り早い入口です。
