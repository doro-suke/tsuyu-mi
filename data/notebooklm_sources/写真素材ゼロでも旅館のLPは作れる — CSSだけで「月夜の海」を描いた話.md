## 本文
はじめに
ホテル学専攻の大学生です。前回、AIと一緒にES添削ツールを作って公開した話を書きましたが、今回はポートフォリオ2作品目として**架空の旅館のランディングページ（LP）**を作りました。
このLP、実は画像を1枚も使っていません。ヒーローの夜空も、月も、客室の「写真」も、すべてCSSです。今回はその理由と作り方を書きます。

 なぜ画像なしで作ったのか
ポートフォリオ用の架空サイトを作るとき、一番困るのが写真素材です。

フリー素材を使うと「どこかで見たLP」になる
有料素材はデモのために買いたくない
実在の旅館の写真は当然使えない

そこで発想を変えました。実案件では必ずお客様の写真に差し替わるのだから、デモの段階では「写真がなくても世界観が成立する構造」を作っておけばいい。むしろ、写真の枠だけ用意しておけば、実案件では差し替えるだけで完成します。

 CSSだけで「月夜の海」を作る
ヒーローセクションは3つのグラデーションの重ね合わせでできています。
.hero{
  background:
    /* 月あかりの暖色（右上にふわっと） */
    radial-gradient(ellipse at 70% 20%, rgba(255,244,214,.35), transparent 50%),
    /* 夜空から海へのグラデーション */
    linear-gradient(180deg, #16233a 0%, #243a5e 45%, #3d5a80 75%, #6a8caf 100%);
}
.moon{
  width:110px; height:110px; border-radius:50%;
  background:radial-gradient(circle at 40% 40%, #fff8e1, #e8d9a0);
  box-shadow:0 0 80px 30px rgba(255,244,214,.25); /* 月暈（つきがさ） */
}
ポイントは box-shadow を「光」として使うことです。ぼかし半径を大きく取ると、月の周りの淡い光（月暈）が表現できて、一気に「夜」の空気になります。
客室セクションの「写真」も、実はグラデーションの板です。
.room:nth-child(1) .ph{ background:linear-gradient(160deg,#243a5e,#6a8caf); }
.room:nth-child(2) .ph{ background:linear-gradient(160deg,#4a3f2e,#b98d4f); }
「写真：海側和室（イメージ）」とテキストを置いておけば、デモとしては十分伝わり、実案件では background:url(...) に差し替えるだけです。

 宿泊LPの構成は「王道」に従った
デザインは遊びましたが、構成は宿泊業LPの定石通りにしています。

ファーストビュー（世界観＋予約CTA）
選ばれる理由3点
お部屋と料金
お客様の声
アクセス
予約CTA（電話番号つき）

大学でホスピタリティ産業を学んでいるのですが、小規模旅館の集客はOTA（予約サイト）依存からの脱却が長年のテーマです。自社ページから直接予約してもらうには「不安を消す順番」で情報を並べる必要があって、それがこの王道構成の意味だと理解しています。
CTAボタンをヘッダー・ヒーロー・末尾の3箇所に置いているのも、スマホでどこまでスクロールした人でも1タップで予約導線に乗れるようにするためです。

 AI（Claude Code)との分業
今回も実装はほぼClaude Codeです。ただ、前回と同じく人間側の仕事がありました。


業界知識の注入：「1泊2食付・税込・〜／人」という料金表記、チェックイン時間、送迎の有無など、旅館のサイトに「あるべき情報」を指示するのは人間の仕事でした

架空であることの明示：実在の施設と誤認されないよう、DEMOバッジとフッター注記を必ず入れる判断

世界観の言語化：「明朝体×紺×金の和モダンで、月と海」という一言を最初に渡せたかどうかで、出てくるものが全然違います
